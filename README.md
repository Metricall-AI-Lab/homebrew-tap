# Stratl Homebrew tap

```bash
brew install metricall-ai-lab/tap/stratl
stratl --version
```

`stratl` verifies Stratl evidence bundles offline. The cask in `Casks/` is written by the
release process on every verifier release; binaries and checksums come from
[stratl-releases](https://github.com/Metricall-AI-Lab/stratl-releases/releases).
